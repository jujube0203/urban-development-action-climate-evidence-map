# Data reuse

The repository's MIT License applies to the Python code and accompanying
workflow documentation. It does not grant reuse rights for files in this
directory.

`input_sample.csv` is a blank input template. `city_attributes.xlsx` contains
attributes assembled from external city data sources. Source-specific reuse
conditions and attribution should be checked before redistributing or reusing
those attributes.

If a full research dataset is added here, its bibliographic records (including
article titles and abstracts) and any third-party attributes remain subject
to their respective rights and source terms. A repository license cannot grant
permissions held by the original publishers or data providers. Document the
provenance, terms, and required citations for every externally sourced column
before publishing such a dataset.
